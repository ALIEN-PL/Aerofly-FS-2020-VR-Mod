# Game Expansion Files (OBB)

Place your legally acquired Aerofly FS 2020 expansion files here before running `install_on_quest.bat`:

- `main.202043.com.aerofly.aeroflyfs2020.obb`
- `patch.202013.com.aerofly.aeroflyfs2020.obb`

*Note: If you have already installed these OBB files onto your Quest headset (at `/sdcard/Android/obb/com.aerofly.aeroflyfs2020/`), you can skip placing them here.*
